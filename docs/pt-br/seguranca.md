# Política de Segurança

🌐 **Idioma:** [English](../../SECURITY.md) · Português

## Versões suportadas

O oito2_iced ainda não tem nenhuma versão lançada: todo crate está na versão `0.0.0` e os apps os usam como dependências Git. Até o primeiro lançamento, as correções de segurança chegam somente ao branch `main`.

| Versão | Suportada |
|---|---|
| Branch `main` | ✅ |
| Versões lançadas | Nenhuma ainda |

## Como relatar uma vulnerabilidade

Relate vulnerabilidades **em particular**, nunca por uma issue, pull request ou discussão pública.

Use o relato privado de vulnerabilidades do GitHub: abra a [aba **Security**](https://github.com/oito2/oito2_iced/security) do repositório e escolha **Report a vulnerability**.

## O que incluir

- O crate afetado (`oito2_iced`, `oito2_iced_settings`, `oito2_iced_themes`, `oito2_iced_syntax`, `oito2_iced_extras`, `oito2_iced_files`) ou o showcase, e o commit que você usa.
- O sistema operacional e, no Linux, a distribuição, o ambiente desktop e a sessão (X11 ou Wayland), quando for relevante.
- Os passos para reproduzir, uma prova de conceito se você tiver, e o impacto que você espera.

## O que esperar

Os mantenedores confirmam o recebimento do relato no mesmo aviso privado, investigam o problema e mantêm você informado por lá. Quando a correção estiver pronta, ela chega ao `main` e o aviso é publicado, com crédito a você, a menos que prefira ficar anônimo.
