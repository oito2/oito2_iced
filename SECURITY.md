# Security Policy

🌐 **Language:** English · [Português](docs/pt-br/seguranca.md)

## Supported Versions

oito2_iced has no release yet: every crate is at version `0.0.0` and apps use them as Git dependencies. Until the first release, security fixes land on the `main` branch only.

| Version | Supported |
|---|---|
| `main` branch | ✅ |
| Released versions | None yet |

## Reporting a Vulnerability

Please report vulnerabilities **privately**, never through a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: open the repository's [**Security** tab](https://github.com/oito2/oito2_iced/security) and choose **Report a vulnerability**.

## What to Include

- The affected crate (`oito2_iced`, `oito2_iced_settings`, `oito2_iced_themes`, `oito2_iced_syntax`, `oito2_iced_extras`, `oito2_iced_files`) or the showcase, and the commit you use.
- The operating system, and on Linux the distribution, desktop environment and session (X11 or Wayland), when relevant.
- Steps to reproduce, a proof of concept if you have one, and the impact you expect.

## What to Expect

The maintainers acknowledge the report in the same private advisory, investigate it, and keep you informed there. When a fix is ready, it lands on `main` and the advisory is published, crediting you unless you prefer to stay anonymous.
